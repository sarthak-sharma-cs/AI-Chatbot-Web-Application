# AI Chatbot (Gemini API)

A full-stack AI chatbot built using React (Vite) and Google Gemini API. The application provides real-time conversational responses and is deployed using Vercel.

---

## Features

* Real-time chatbot interaction
* Fast and responsive UI
* Secure backend API integration
* Serverless deployment

---

## Tech Stack

* Frontend: React, Vite, Tailwind CSS
* Backend: Vercel Serverless Functions
* AI: Google Gemini API
* Deployment: Vercel

---

## Project Structure

```
aura-chat-main/
│── src/
│── api/
│   └── chat.js
│── index.html
│── package.json
```

---

## Installation and Setup

### Clone the repository

```
git clone https://github.com/sarthak-sharma-cs/AI-Chatbot-Web-Application
```

### Navigate to project

```
cd aura-chat-main
```

### Install dependencies

```
npm install
```

### Create environment file

```
GEMINI_API_KEY=your_api_key
```

### Run locally

```
npm run dev
```

---

## Deployment

The project is deployed using Vercel.

* Root Directory: aura-chat-main
* API Endpoint: /api/chat
* Environment Variable: GEMINI_API_KEY
